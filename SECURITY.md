# Security policy

Please do not submit private keys, seed phrases, customer secrets, or confidential financial data in issues.

PayProof X is a read-only static app. Report a suspected vulnerability by opening a GitHub Security Advisory in the repository, if enabled, or by contacting the maintainer privately. Until a contact address is configured, do not include exploitable details in public issues.

Before using the app to accept commercially important payments, independently confirm the token contract, transaction receipt, recipient address, amount, and finality in a trusted block explorer. The project does not provide custody or financial services.
